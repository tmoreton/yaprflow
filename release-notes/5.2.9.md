# Yaprflow 5.2.9

This maintenance release polishes provider setup and update settings:

- API keys can now be pasted normally with Command-V or the standard Edit
  menu.
- Update settings are reduced to a clear version row, a Check Now action, and
  one automatic-updates switch.
- Automatic updates now use one control for both checking and downloading.

Dictation, meeting recording, and saved notes are unchanged.
