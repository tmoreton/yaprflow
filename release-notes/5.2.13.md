# Yaprflow 5.2.13

This release improves recording feedback and permission recovery:

- Quick Dictation now shows a live microphone-level waveform while recording
  instead of displaying partial transcription text.
- Dictation continues to transcribe natural, bounded sections with Parakeet,
  keeping long recordings memory-safe while preserving final accuracy.
- Meeting Notes now lets ScreenCaptureKit verify Screen & System Audio access
  directly after a Sparkle update instead of stopping on a stale preliminary
  permission result.
- If macOS genuinely denies capture, Yaprflow still provides a direct route to
  the correct Privacy & Security settings.

All speech recognition remains on the Mac. Audio is not uploaded for
transcription.
