# Yaprflow 5.2.20

- Allows a modifier key such as Option to be used by itself as the Quick
  Dictation shortcut. A quick press and release toggles dictation, while normal
  Option-key combinations continue to work in other apps.
- Adds an optional Auto-paste setting that inserts completed dictation at the
  current cursor after copying it to the clipboard.
- Guides you through granting Accessibility access when Auto-paste needs it.

Speech recognition remains on-device and raw audio is not saved. Auto-paste
uses macOS Accessibility access only to send the standard Paste shortcut to the
app you are currently using.
