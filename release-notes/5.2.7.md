# Yaprflow 5.2.7

This release completes the new unified dictation and meeting workflow:

- Dictations and meetings now share one clean, newest-first library while
  retaining clear item labels, meeting notes, transcripts, and deletion.
- Meeting audio is processed after recording so microphone and Mac audio can be
  separated more reliably without displaying unstable interim speaker text.
- Meeting and dictation outputs use one shared set of presets. Prompts can be
  edited from Settings and used with the configured Apple Intelligence,
  OpenAI, OpenRouter, or Ollama provider.
- Meeting permissions now guide first-time users directly through macOS Screen
  and System Audio access and the required restart.
- Settings now shows the exact installed app version beside update controls.
- Direct purchasers can receive a private cross-device download link by email;
  newsletter enrollment remains optional and requires explicit consent.

Quick Dictation remains live and local. Meeting audio is not retained after
transcription.
