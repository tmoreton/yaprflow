# Yaprflow 5.2.1

This release makes the Mac workspace simpler and more consistent:

- Meetings and quick dictations now live together in one clean Library.
- Both recording types use the same AI workflow for summaries, presets, and
  follow-up questions.
- Meetings receive automatic titles and support deletion from the Library.
- Meeting summary parsing is more resilient when an AI provider returns an
  unexpected response shape.
- Duplicate navigation, controls, and menu items have been removed, and
  Settings has been reduced to the options that matter.

Quick Dictation and Meeting Notes continue to transcribe locally, and raw
meeting audio is not retained.
