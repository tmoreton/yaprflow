# Yaprflow 5.2.6

This release improves Meeting Notes audio reliability and first-run setup:

- Meeting mode uses macOS voice processing to reduce speaker echo and prevent
  Mac playback from being transcribed as both **Me** and **Them**.
- Screen and System Audio permission is checked before capture starts. A real
  denial is now distinguished from an audio-device startup failure, so Yaprflow
  no longer sends every capture error back through permission setup.
- After Screen and System Audio is approved for the first time, onboarding
  offers the restart macOS requires to activate that permission cleanly.
- The Settings item and window now open sharp, focused, and ready to use.

Quick Dictation remains unchanged. Meeting transcription continues to run
locally, and raw meeting audio is not retained.
