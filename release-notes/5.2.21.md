# Yaprflow 5.2.21

- Fixes Auto-paste permission setup so macOS shows the correct prompt and can
  paste completed dictation at the current cursor.
- Keeps the finished text on the clipboard when permission has not yet been
  granted.

Speech recognition remains on-device and raw audio is not saved. Auto-paste
uses macOS permission only to send the standard Paste shortcut to the app you
are currently using.
