# Contributing

Bug reports, feature requests, reproduction steps, and other feedback are
welcome through the repository's issue tracker.

Yaprflow does not currently accept third-party source-code or asset
contributions unless the copyright owner approves the contribution and both
parties complete a separate written contributor agreement before submission.
Please do not submit a pull request containing code or assets without that
prior agreement; unsolicited patches will not be merged.

This policy keeps ownership and licensing rights clear so Yaprflow can remain
available under a noncommercial public source license while also offering
separate commercial licenses. Contact <tim@yaprflow.com> before preparing a
code contribution.
